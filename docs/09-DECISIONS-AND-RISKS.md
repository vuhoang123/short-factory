# 09 — Decisions, Assumptions, External Blockers

## Decisions made
Hybrid personal MVP with SaaS-ready workspace boundaries; semi-automatic default; TypeScript-first; manual import as first complete source; official platform APIs only; content rights are non-bypassable; TikTok export until eligible.

## Assumptions requiring real-world verification
- OAuth app review, business verification, current permission scopes, user entitlement and access to each publisher API.
- API rate limits, quota, moderation, posting format and content originality restrictions.
- Threads discovery capabilities for granted access; Reddit commercial data agreement status.
- Rights and licenses for background videos, fonts, sound and story text.

## External blockers
`BLOCKED_EXTERNAL` for provider permission/API review; `BLOCKED_RIGHTS` for source/asset license; `NEEDS_ACTION` for creator handoff. Admin dashboard must surface blockers plainly.

## Open choices for project owner
Domain/branding, final voice providers and costs, authorized data source list, specific content topics, first media templates, account/creator approval process, retention rules and jurisdictional rights review.

## Non-goals
No fake capability success; no stealth scraping; no mass reposting without rights; no promises of algorithmic virality/monetization.
